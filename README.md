# Ethan Largo — Portfolio Website

A dark, Apple-inspired portfolio site built with plain HTML, CSS, and
JavaScript. No frameworks, no build step — just open it and it works.

## View the site

Double-click **index.html** (or right-click → Open with → your browser).

## Add your projects ✏️

Open **projects.js** in any editor. Copy one of the example blocks, fill in
your info, save, and refresh the browser. Each project can have:

- a title, description, and tech tags
- an emoji **or** a screenshot (drop the image file into the `images/` folder)
- optional "Live demo" and "Source code" links

Your skills list (the chips in the Skills section) is at the bottom of the
same file.

## Edit your bio ✏️

Open **index.html** and look for the comment `EDIT YOUR BIO HERE` in the
About section. The contact email is near the bottom of the same file.

## Change the colors 🎨

Open **styles.css** — the colors live in the `:root` block at the very top.
Try changing `--accent` and `--accent-2` for a whole new vibe.

## Hosting it later (when you're ready)

This site is 100% static, so hosting is free and easy. Two good options:

1. **GitHub Pages** — push this folder to a GitHub repo, then in the repo's
   Settings → Pages, set the source to your main branch. Done.
2. **Netlify** — go to [netlify.com](https://www.netlify.com), sign up free,
   and literally drag this folder onto the dashboard. It's live in seconds.

## Files

| File          | What it is                                      |
| ------------- | ----------------------------------------------- |
| `index.html`  | Page structure + your bio                       |
| `projects.js` | **Your projects & skills — edit this one most** |
| `styles.css`  | All the visuals (colors, layout, animations)    |
| `main.js`     | Builds the project cards, runs the animations   |
| `images/`     | Put project screenshots here                    |
